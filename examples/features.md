# Feature tour

This is a second document, opened from a relative link. Notice that the first
tab kept its scroll position.

## Tabs

| Action                    | How                                    |
| ------------------------- | -------------------------------------- |
| Switch                    | Click, `Ctrl+Tab`, `Ctrl+1…9`          |
| Close                     | ✕ button, middle click, `Ctrl+W`       |
| Reorder                   | Drag a tab                             |
| More                      | Right-click a tab                      |

## Live reload

Edit this file in any editor and save — the tab refreshes instantly and keeps
your place. A dot appears on background tabs that changed.
